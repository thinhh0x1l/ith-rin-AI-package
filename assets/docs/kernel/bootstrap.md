# Bootstrap

Use this file at the start of every session.

1. Read `AGENTS.md`.
2. If the task matches a skill, load `using-hub` first.
3. Route the task:
   - unclear goal → ask one question at a time;
   - need context → produce a context brief;
   - need a plan → produce a plan with `## Task N:` sections;
   - approved plan → execute with tests and evidence;
   - bug → root cause before fixing;
   - about to report done → verify and show evidence;
   - after the session → capture reusable knowledge.
4. Use the smallest context that answers the question.
5. Never claim success without evidence.
6. Project-specific rules override this bootstrap.
